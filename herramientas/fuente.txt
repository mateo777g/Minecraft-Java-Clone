// Cada glifo empieza en la columna donde está su carácter en la cabecera; entre glifo y glifo va un espacio.
// '#' es un píxel pintado y '.' uno vacío. Los glifos van pegados a la izquierda: el juego mide el
// ancho de cada uno buscando su última columna pintada.
//
// Filas: 0-1 acento de las mayúsculas, 3-9 mayúsculas y números, 5-9 minúsculas (con las astas
// desde la 3 y los acentos en la 2-3) y 10-11 las colas de g, j, p, q, y. La línea base queda
// debajo de la fila 9.
//
// Las líneas que empiezan con // son comentarios. Un carácter que no está aquí se dibuja como '?'.
